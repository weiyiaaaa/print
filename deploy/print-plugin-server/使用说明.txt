飞书打印插件 —— 服务器部署包（无需 npm、无需 node_modules）
==========================================================

里面是什么
  dist\                    插件页面（一定要整个目录一起用）
  server\serve.cjs         静态服务器，零依赖，有 node 就能跑
  server\start.ps1         启动脚本（中文提示都在这里）
  server\install-task.ps1  注册开机自启 + 放行防火墙
  server\fix-net.ps1       单独修防火墙（放行端口与 node.exe）
  server\diagnose.ps1      体检：监听/防火墙/任务/连通性
  启动服务.cmd             双击临时启动（窗口关掉就停）
  安装为开机自启.cmd       右键「以管理员身份运行」→ 常驻服务
  卸载开机自启.cmd         同上，卸载
  修复网络.cmd             右键「以管理员身份运行」→ 放行防火墙
  诊断.cmd                 双击体检，出问题时先跑这个
  使用说明.txt             本文件


★★ 飞书里地址怎么写（最常见的坑，先看这段） ★★

  正确：  http://192.168.0.126:8666/print/
  错误：  https://192.168.0.126:8666      ← 多了 s！本服务是 http，浏览器会报
                                            「发送了无效的响应」
  错误：  192.168.0.126                   ← 少了端口，浏览器会去连 80 端口，
                                            结果是「响应时间太长」
  错误：  http://192.168.0.126:8666        ← 少了 /print/ 路径

  四点必须满足：http:// 开头、带 :8666、路径为 /print/、结尾加 /
  通过公司域名访问：https://feishu-print.tech-long.com:5443/print/
  Nginx 使用 location /print/，proxy_pass  http://127.0.0.1:8666;（末尾不要加 /，保留路径前缀）


第一步：装 Node.js（只需一次）
  打开 https://nodejs.org/zh-cn ，下载 LTS 版本，一路下一步。
  装完把已经打开的 cmd 窗口全部关掉（环境变量要重新加载）。
  验证：cmd 里执行 node -v，能看到版本号即可。

第二步：先手动跑一次，确认能打开
  双击「启动服务.cmd」，窗口里会出现
    本机访问: http://127.0.0.1:8666/print/
  用浏览器打开这个地址，能看到插件界面就说明服务正常。
  （不在飞书里会提示"需在飞书多维表格的插件面板中运行"，这是正常的）
  换端口：在该目录的 cmd 里执行  启动服务.cmd 9100

第三步：装成常驻服务（关键：这一步同时解决"服务会停"和"防火墙没放行"）
  右键「安装为开机自启.cmd」→「以管理员身份运行」
  它做三件事：建开机自启任务（SYSTEM，不登录也跑）、放行防火墙、自检。
  跑完会打印本机地址和局域网地址，形如
    http://127.0.0.1:8666/print/
    http://192.168.0.126:8666/print/
  装完就可以把所有黑窗口关掉，服务不会停。

第四步：填到飞书
  飞书多维表格 → 右上角「插件」→「自定义插件」→「新增插件」
  地址按上面"地址怎么写"那段填。
  注意输入框里的灰字是示例（占位符），不是已经填好的值 —— 要真的点进去输一遍。

第五步：验证
  在【另一台电脑】的浏览器打开 http://192.168.0.126:8666/print/
  能打开，再回飞书刷新插件面板。打不开就双击「诊断.cmd」。


日常维护
  改页面：把新的 dist 目录整个替换掉，页面刷新即可（不用重启服务）
  看状态：管理员 PowerShell
          Get-ScheduledTask -TaskName PrintPluginServer | Get-ScheduledTaskInfo
  重启：  Restart-ScheduledTask -TaskName PrintPluginServer
  卸载：  右键「卸载开机自启.cmd」以管理员身份运行
  换端口：先「卸载开机自启.cmd」，再执行
          powershell -ExecutionPolicy Bypass -File server\install-task.ps1 -Port 9100


出问题按这个顺序排查
  1) 双击「诊断.cmd」，看哪几项是 [X]
     - 端口 8666 没有进程监听  → 服务没跑，重做第三步
     - 没有放行 8666 的防火墙规则 → 右键「修复网络.cmd」以管理员运行
     - 本机 127.0.0.1 打不开    → 服务没跑，或端口被占用
  2) 本机能开、别的电脑打不开 → 防火墙 / 不在同一网段 / 无线 AP 隔离
  3) 飞书里报"无效的响应"     → 地址写成了 https，改成 http
  4) 飞书里一直转圈           → 地址少了端口，或服务没跑


关于 https（仅当飞书不接受 http 时才需要）
  本包提供的是 http 服务。如果飞书强制要求 https，需要给服务器配证书：
  自签证书的话，每台访问的电脑都要装一次根证书，否则浏览器会拦。
  遇到这种情况再说，可以另外配。
